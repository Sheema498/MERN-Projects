JWT - JSON Web Token 
        is secure Token generated by the Server after succsesful Login

Why JWT ?

without JWT 

    user logs in
        |
    server remembers Session
        |
    need Session storage

With JWT 
    user logs in
        |
    server Creates Token
        |
    Client stores Token
        |
    client send Token With Request


JWT Structure
    JWT Contains 3 parts :

        HEADER.PAYLOAD.SIGNATURE
        xxxxx.yyyyyy.zzzzz

HEADER :
 Contains Algorithmm information :
    {
        "alg" :"HS256",
        "typ":"JWT"
    }
PAYLOAD : contains user information
    {
        "id":101,
        "username":"Mubarak"
    }
SIGNATURE : creating header payload and secret key
    header
      +
    payload
      +
    secret Key

used to verify tkoen authenticity

              User
                │
                │ Login
                ▼
              Server
                │
                │ Verify Credentials
                ▼
              Generate JWT
                │
                ▼
              Send Token
                │
                ▼
              Browser Stores Token
                │
                ▼
              Future Requests
                │
                ├── Token Attached
                ▼
              Server Verifies Token
                |
                |
                ▼
              Access Granted
